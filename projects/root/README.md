# angular-develop-universe
This Angular library was generated with Angular CLI version 15.2.0, but it is strongly recommended to use it only in projects with the most recent versions of Angular (17.0.0) due to the use of Signal for various components.

## Scope
The primary goal of this library is to expedite the development of Internet of Things (IoT) interfaces. Notably, the styling of the components has not been rigidly implemented, allowing end-users the flexibility to modify shapes and colors as desired.

## Future Developments
The development team is committed to expanding the range of components and services continually. The aim is to empower users of this library to accelerate the development of IoT projects. Additionally, a secondary goal is to establish development standards that enhance the solidity and maintainability of final projects over time.

## Cognito Module
The Cognito module facilitates the interaction between the application and the AWS identity provider. This module supports two authentication modes: login_required and check_login. Alongside flow management, the module offers directives and interceptors to secure components and HTTP calls through bearer tokens. User data is stored in the Ngrx store.

## Inputs Module
The Inputs module provides various components implementing standard browser inputs, such as CVA (Control Value Accessor). Each component is designed to display help, success, and error messages. Moreover, they include all the attributes necessary to ensure a high level of accessibility. To maximize the utility of this module, it is recommended to develop application forms using reactive forms.
